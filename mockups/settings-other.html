How to pair
1
Install the agent-deck app on your Android device.
2
Open the app and tap Scan QR to connect on the pairing screen.
3
Scan the QR code displayed above. The app will store your server URL and auth token automatically.
4
Make sure both devices are on the same Tailscale network.
Auth Token
Used to authenticate remote devices over Tailscale
This token is printed to the server terminal on startup. Copy it to authenticate from remote browsers or the mobile app.
⚠ Warning: Rotating the token will immediately invalidate all existing sessions. You'll need to:
  • Re-enter the new token on any remote browsers accessing via Tailscale
  • Re-scan the QR code on the mobile app
